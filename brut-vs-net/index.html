Brut vs. net: care este diferența

Una dintre cele mai frecvente confuzii la salariu este diferența dintre brut și net. Brutul este valoarea înainte de rețineri, iar netul este suma efectiv primită de angajat.

Ce este salariul brut?

Salariul brut este valoarea salarială înainte de aplicarea contribuțiilor, impozitului și deducerilor relevante.

Ce este salariul net?

Salariul net este suma rămasă după reținerile aplicabile și este, în mod obișnuit, suma virată angajatului.

De ce diferă?

Din brut se calculează și se rețin contribuțiile sociale și impozitul, cu aplicarea eventualelor deduceri și facilități.
